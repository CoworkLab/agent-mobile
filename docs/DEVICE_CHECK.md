# Phone pe kaise test karna hai

Ye file simple Hinglish me hai. Sirf ek baar karna hai, sabse aakhir me.

1. APK install karo (Settings me "Install unknown apps" on karna padega).
2. App kholo -> Accessibility on karo -> "Allow restricted settings" bhi on karo (Android 13+).
3. Settings me apna Gemini API key paste karo.
4. Ye 5 aasan kaam try karo:
   - "Settings kholo aur Wi-Fi ka switch dabao"
   - "Subah 6 baje ka alarm laga do"
   - "WhatsApp pe mummy ko likho kal aa raha hu" (Send se pehle permission maangega)
   - "Gallery ki latest video 10 second trim karo"
   - "PhonePe kholo" (mana kar dena chahiye)
5. Kuch fail ho to: Log Viewer kholo -> Copy all -> OpenHands ko bhej do.

## Sirf asli phone pe hi check ho sakta hai

- OEM battery killers (Xiaomi, Oppo, Vivo) background service ko band kar dete hain.
- Aapka asli video editor app (uska timeline custom hota hai, drag fail ho sakta hai).
- Asli banking apps ka screenshot aur accessibility block karna.
- Lock screen agent nahi khol sakta.
